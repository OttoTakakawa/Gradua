## 一、项目总览

这是一个纯静态 HTML/CSS/JS 毕业设计展示站，无构建工具、无框架、无包管理器。所有页面通过自实现的 PJAX 体系实现无刷新跳转，配合滚轮翻页和导航指示器动画。

### 目录结构

```
Gradua/
├── index.html              # 首页（PJAX 主壳）
├── shared.css              # 全站公共样式
├── shell.js                # 全站公共脚本（PJAX + 导航 + 滚轮翻页）
├── images/                 # 全站共享图片
├── models/                 # 3D 模型（.glb）
│
├── about/index.html        # 项目介绍
├── research/index.html     # 问题研究
├── design/index.html       # 核心设计（最复杂，含 SVG 交互 + model-viewer）
├── chapters/
│   ├── index.html          # 章节导览（4 章卡片入口）
│   ├── chapter-1/index.html  # 第一章 · 孤独的城市
│   ├── chapter-2/index.html  # 第二章 · 萨沙的家
│   ├── chapter-3/index.html  # 第三章 · 皮埃尔的梦想
│   └── chapter-4/index.html  # 第四章 · 太空之梦
├── process/index.html      # 制作过程
└── thanks/index.html       # 感谢页
```

### 页面线性顺序

```
index → about → research → design → chapters → [ch1 → ch2 → ch3 → ch4] → process → thanks
```

这个顺序定义在 `shell.js` 的 `PAGE_ORDER` 数组中，决定了滚轮翻页方向和导航指示器的移动方向。

## 二、PJAX 路由体系

### 核心文件：`shell.js`

`shell.js` 是全站唯一的公共脚本，负责：

1. **PJAX 页面切换**（fetch → DOMParser → swap）
2. **导航指示器动画**（滑块跟随 active 链接）
3. **滚轮翻页**（顶部上滑回上一页、底部下滑进下一页）
4. **滚动揭示动画**（IntersectionObserver 驱动的 reveal-item）
5. **浏览器历史管理**（pushState + popstate）

### PJAX 工作流程

```
用户点击导航链接 / 滚轮触发翻页
  ↓
shell.js 判断目标 URL 是否为 PJAX 目标（isPjaxTarget）
  ↓ 是 → fetch 目标页 HTML
  ↓ 否 → window.location.href 全页跳转
  ↓
DOMParser 解析目标页 HTML
  ↓
swapPage() 执行：
  1. 替换 body class（page-xxx）
  2. 替换 #page-styles 内容
  3. 替换 #page-content 内容
  4. 更新导航 active 状态
  5. 执行 #page-config（通过 eval 设置 __pageConfig）
  6. 移除旧 #page-script，注入新 #page-script
  7. pushState 更新 URL
  8. 重置滚轮状态，scrollTo(0,0)
  9. 触发导航指示器动画 + reveal 动画
```

### isPjaxTarget 判断逻辑

```javascript
function isPjaxTarget(href) {
  if (/chapter-\d+/.test(href)) return false;  // 章节子页面不走 PJAX
  if (/(?:about|research|design|chapters|process|thanks)\/index\.html/.test(href)) return true;
  if (/(?:^|\/|\.\/)index\.html$/.test(href)) return true;
  return false;
}
```

**关键点**：chapter-1~4 的 URL 包含 `chapter-\d+`，被排除在 PJAX 之外。这意味着：
- 章节间导航（ch1→ch2）→ 全页加载
- 章节到主站导航（ch1→项目介绍）→ 走 PJAX（前提是章节页有正确的 DOM 结构）

### 页面模板结构（PJAX 兼容）

每个页面必须包含以下结构，shell.js 才能正确 swap：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题 — Within · 协作同行</title>
  <link rel="stylesheet" href="../shared.css">
  <style id="page-styles">
    /* 页面特有样式，PJAX 切换时会被整体替换 */
  </style>
</head>
<body class="page-xxx">

<nav class="nav">
  <span class="nav-indicator" aria-hidden="true"></span>
  <a href="../index.html">首页</a>
  <a href="../about/index.html" class="active">项目介绍</a>
  <a href="../research/index.html">问题研究</a>
  <a href="../design/index.html">核心设计</a>
  <a href="../chapters/index.html">章节导览</a>
  <a href="../process/index.html">制作过程</a>
  <a href="../thanks/index.html">感谢</a>
</nav>
<div class="prev-arm-hint" aria-hidden="true"></div>
<div class="next-arm-hint" aria-hidden="true"></div>

<div id="page-content">
  <div class="wrap">
    <!-- 页面内容 -->
  </div>
  <footer>Within · 协作同行 ｜ 愿每一段旅程都有人同行</footer>
</div>

<script id="page-config">
window.__pageConfig = {
  current: 'about',           // 当前页面在 PAGE_ORDER 中的 key
  prev: '../index.html',      // 上一页 URL（null 表示无上一页）
  next: '../research/index.html'  // 下一页 URL（null 表示无下一页）
};
</script>
<script src="../shell.js"></script>

</body>
</html>
```

### 关键 DOM ID 说明

| ID | 作用 | shell.js 如何使用 |
|---|---|---|
| `page-styles` | 页面特有样式容器 | swap 时替换 textContent |
| `page-content` | 页面内容容器（含 wrap + footer） | swap 时替换 innerHTML |
| `page-config` | 页面配置脚本 | swap 时通过 eval 执行，设置 `__pageConfig` |
| `page-script` | 页面特有脚本（可选） | swap 时移除旧的、注入新的 |

### body class 命名规范

- 主站页面：`page-about`、`page-research`、`page-design`、`page-chapters`、`page-process`、`page-thanks`
- 章节页面：`page-chapter-1`、`page-chapter-2`、`page-chapter-3`、`page-chapter-4`
- 首页：无 page-xxx class

body class 在 PJAX swap 时会被替换，因此 `page-styles` 中的页面特有样式**必须**使用 `body.page-xxx` 作用域，否则切换页面后样式会残留。

## 三、样式体系

### `shared.css` 提供的基础样式

以下样式由 shared.css 统一提供，**各页面不得重复定义**：

- Reset（`*, *::before, *::after`）
- `html` 滚动行为（overflow-y, scrollbar-gutter, overscroll-behavior-y）
- `:root` CSS 变量（--text-main, --text-dark, --text-soft, --blue, --cyan, --cyan-deep, --purple, --warm, --border, --shadow, --shadow-hover）
- `body` 基础排版（font-family, color, overflow）
- `body::before` 菱形纹理叠加层
- `body::after` 页面离场遮罩层（opacity 由 body class 控制）
- `body.is-leaving-*` / `is-entering-*` 离场/入场动画
- `.nav` 导航栏布局
- `.nav-indicator` 导航滑块
- `.nav a` 导航链接
- `#page-content > *` 内容区过渡
- `.reveal-item` / `.reveal-item.is-visible` 滚动揭示动画
- `.prev-arm-hint` / `.next-arm-hint` 滚轮翻页提示
- `.wrap` 内容区基础定位（position, z-index, margin, padding）
- `.eyebrow` 小标题基础样式
- `footer` 页脚基础样式
- 700px 媒体查询中的 nav / wrap / arm-hint 响应式规则
- `prefers-reduced-motion` 媒体查询

### `page-styles` 中应包含的内容

每个页面的 `<style id="page-styles">` 只需包含：

1. **页面特有 CSS 变量**（如 `--accent`、`--accent-soft`）
2. **body 背景覆盖**（`body.page-xxx { background: ... }`）
3. **body::after 背景覆盖**（离场遮罩的色调）
4. **.nav 背景覆盖**（导航栏色调）
5. **.wrap 宽度**（主站 1520px，章节 1120px）
6. **.eyebrow 颜色覆盖**
7. **页面特有组件样式**（hero、card、tag-row 等）

### 版心宽度规范

- 主站页面（about/research/design/chapters/process/thanks）：`width: min(1520px, calc(100% - 56px))`
- 章节页面（chapter-1~4）：`width: min(1120px, calc(100% - 36px))`

## 四、导航系统

### 导航栏结构

```html
<nav class="nav">
  <span class="nav-indicator" aria-hidden="true"></span>
  <a href="...">首页</a>
  <a href="..." class="active">当前页</a>
  ...
</nav>
```

### 导航指示器动画

1. 页面加载时，从 `sessionStorage` 读取上一页的指示器位置
2. 先将指示器瞬移到上一页位置（immediate = true，禁用 transition）
3. 双重 rAF 后，将指示器动画移动到当前页位置
4. 每次导航离开时，保存当前指示器位置到 sessionStorage

### 导航链接点击拦截

shell.js 拦截 `.nav a` 的点击事件：
- 如果目标 URL 是 PJAX 目标 → `loadPage()` 无刷新切换
- 如果不是 → `window.location.href` 全页跳转
- 点击模式使用 `is-leaving-click` 动画（缩放 + 淡出，280ms）

## 五、滚轮翻页系统

### 状态机

```
正常滚动
  ↓ 滚到顶部 + 继续上滑（deltaY < -12）
prevArmed（显示"滚轮上滑，回到前一页"提示 + 内容下拉 240px）
  ↓ 继续上滑确认（deltaY < -8）
执行 loadPage(prev, 'wheel', 'prev')
  ↓ 或反向滑动取消（deltaY > 10）
回到正常滚动

正常滚动
  ↓ 滚到底部 + 继续下滑（deltaY > 12）
nextArmed（显示"滚轮下滑，前往下一页"提示 + 内容上推 240px）
  ↓ 继续下滑确认（deltaY > 8）
执行 loadPage(next, 'wheel', 'next')
  ↓ 或反向滑动取消（deltaY < -10）
回到正常滚动
```

### 防抖参数

| 参数 | 值 | 含义 |
|---|---|---|
| `armedGraceMs` | 960 | arm 触发后的锁定时间，期间反向滑动不取消 |
| `armedConfirmCooldownMs` | 360 | arm 触发后确认翻页的最短等待 |
| `pullOpenDistance` | 240 | arm 时内容的位移量（px） |
| `threshold` | 4 | 判断"在顶部/底部"的容差（px） |
| `delay` | 420 | 翻页动画时长（ms） |

### 离场动画方向

| 方向 | body class | 内容位移 | 遮罩 |
|---|---|---|---|
| 下一页（wheel） | `is-leaving-next` | translateY(-24px) + blur(3px) | 渐显 |
| 上一页（wheel） | `is-leaving-prev` | translateY(24px) + blur(3px) | 渐显 |
| 点击导航 | `is-leaving-click` | scale(0.985) | 渐显 |

## 六、滚动揭示动画

shell.js 在每次页面加载/PJAX切换后，根据 `state.currentPage` 选择要观察的选择器：

```javascript
var selectorMap = {
  about: ['.hero', '.section', '.hero-actions'],
  design: ['.hero-note', '.section'],
  thanks: ['.thanks-card'],
  research: ['.hero-note', '.section'],
  process: ['.chapter-section', '.section-block']
};
```

被选中的元素会添加 `.reveal-item` class，通过 IntersectionObserver 在进入视口时添加 `.is-visible`。前 2 个元素立即显示，其余等待滚动触发。

## 七、页面特有脚本

### `design/index.html` — 最复杂的页面

包含 `<script id="page-script">`，约 300+ 行，主要逻辑：

1. **机制图 SVG 交互**：hover 高亮节点 + 箭头联动 + 右侧说明区切换
2. **Lightbox**：双击 SVG 放大查看 + 平移
3. **空间布置图交互**：左侧静态图 + 右侧 model-viewer 3D 模型

### `research/index.html` — 图表渲染

包含 `<script id="page-script">`，约 400+ 行，主要逻辑：

1. **Canvas 图表绘制**（柱状图、饼图等）
2. **Tooltip 交互**
3. **矩阵/表格动态渲染**

### model-viewer 依赖

`design/index.html` 通过 CDN 加载：
```html
<script type="module" src="https://unpkg.com/@google/model-viewer/dist/model-viewer.min.js"></script>
```
⚠️ 国内环境可能加载失败，建议本地化。

## 八、章节页面特殊处理

章节页面（chapter-1~4）虽然接入了 PJAX 体系（使用 shared.css + shell.js），但由于 `isPjaxTarget` 排除了 `chapter-\d+` URL，章节间导航始终是全页加载。

### 章节页的 page-config

```javascript
// chapter-1
window.__pageConfig = { current: 'chapters', prev: '../index.html', next: '../chapter-2/index.html' };

// chapter-2
window.__pageConfig = { current: 'chapters', prev: '../chapter-1/index.html', next: '../chapter-3/index.html' };

// chapter-3
window.__pageConfig = { current: 'chapters', prev: '../chapter-2/index.html', next: '../chapter-4/index.html' };

// chapter-4
window.__pageConfig = { current: 'chapters', prev: '../chapter-3/index.html', next: '../../process/index.html' };
```

所有章节页的 `current` 都是 `'chapters'`，因为它们在 PAGE_ORDER 中对应的是 chapters 位置。导航指示器始终高亮"章节导览"。

### 章节页配色

每个章节有独立的 accent 色调和 body 背景：

| 章节 | accent | 色调 |
|---|---|---|
| chapter-1 | #5b9aa0 | 冰蓝（孤独感） |
| chapter-2 | #c4a882 | 暖黄（安全感） |
| chapter-3 | #9385bf | 紫调（梦境感） |
| chapter-4 | #6b8399 | 冷蓝（终章感） |

## 九、硬约束与规范

### 布局约束

- 主站版心宽度：1520px（Wide 级别）
- 章节版心宽度：1120px
- 严禁开启 body 级内部纵向滚动，统一依赖根滚动层

### 签名规范

页脚统一为：`Within · 协作同行 ｜ 愿每一段旅程都有人同行`

### 3D 模型预览

- 必须通过本地静态服务器访问，`file://` 协议下 model-viewer 会因安全限制黑屏
- 启动命令：`python -m http.server 8000`（在项目根目录执行）

### 代码风格

- 不添加注释（除非用户要求）
- CSS 使用 2 空格缩进
- JS 使用 2 空格缩进，var 声明，IIFE 包裹
- shell.js 使用 ES5 语法（兼容性考虑）
- page-script 可以使用 ES6+（现代浏览器支持）

## 十、已知问题与待改进

| 优先级 | 问题 | 说明 |
|---|---|---|
| 🔴 | model-viewer 依赖 unpkg CDN | 国内不稳定，需本地化 |
