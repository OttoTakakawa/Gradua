## 一、架构层面

### 1. ⚠️ CSS / JS 大量重复，未抽取公共资源

全站 10+ 个 HTML 文件，每个都内联了完整的 CSS 和 JS。其中导航栏样式（`.nav`）、二段式翻页脚本、`prev-arm-hint` / `next-arm-hint` 组件、`body::before` 菱形纹理、页面离场动画等逻辑**逐字重复**了 10 遍以上。

**问题**：任何一处样式 / 逻辑修改都需要同步所有文件，极易遗漏（V2.0 已因此出过转义 bug）。

**建议**：抽取 `common.css` 和 `nav.js`（翻页逻辑），各页面仅保留页面专属样式。即使不引入构建工具，纯 `<link>` + `<script src>` 即可消除 80% 的重复。

### 2. ⚠️ 翻页脚本参数硬编码

每个页面的 `prevTarget`、`nextTarget`、`pullOpenDistance`、`armedGraceMs` 等参数都写死在 IIFE 内部。如果链路顺序调整（比如插入新页面），需要逐文件改。

**建议**：用 `data-prev` / `data-next` 属性挂在 `<body>` 或 `.wrap` 上，脚本统一读取，一改全改。

## 二、代码质量

### 3. ⚠️ `index.html` 缺少 `overscroll-behavior-y: none`

项目规范中明确要求全站使用 `overscroll-behavior-y: none`，但首页只有 `scrollbar-gutter: stable`，缺少 `overscroll-behavior-y: none`。在首页下滑跳转时可能出现浏览器默认的弹性过滚动。

### 4. ⚠️ `about/index.html` 的 `body::after` 渐变底色与其他页面不一致

about 页的离场遮罩是 `linear-gradient(180deg, rgba(246,248,251,0.14), ...)`，而 research / design 页是 `linear-gradient(180deg, rgba(245,247,250,0.14), ...)`。虽然差异极小，但在高色准屏幕上可能被察觉。

### 5. ⚠️ `process/index.html` 和 `thanks/index.html` 的 CSS 颜色未使用 CSS 变量

这两个页面直接写了 `color: #4a5560`、`color: #8899a8` 等硬编码色值，而 about / research / design 页面使用了 `var(--text-main)` 等变量。风格不统一，且后续调色时容易遗漏。

### 6. ⚠️ `research/index.html` 图表脚本中的 `countsFromPercentages` 函数存在精度风险

该函数将百分比转回人数时使用 `Math.floor` + 余数分配策略，但输入的 `values` 数组之和未必恰好等于 100。如果未来数据更新导致总和 ≠ 100，人数计算就会偏差。

**建议**：增加归一化步骤，或在数据录入时强制校验 `values.reduce((a,b)=>a+b) === 100`。

## 三、交互体验

### 7. ✅ 章节详情页的翻页链路已修复

chapter-2 的 `prevTarget` → chapter-1，chapter-3 → chapter-2，chapter-4 → chapter-3，形成 `chapters → ch1 → ch2 → ch3 → ch4` 的完整链路。

### 8. ⚠️ 章节页底部 pager 与滚轮跳转的语义冲突

章节详情页底部有 pager 链接，同时滚轮到底也会触发跳转。两种导航方式指向同一目标但体验不同（点击是即时跳转，滚轮有离场动画），可能让用户困惑。

**建议**：保留 pager 作为"显式导航"，滚轮跳转作为"沉浸式推进"，但可以在 pager 旁加一行轻量提示"滚轮下滑自动进入下一章"。

### 9. ⚠️ 首页缺少键盘可访问的"上一页"机制

首页只有下滑 / 下键跳转到 about，没有上滑 / 上键返回（因为它是链头）。但如果用户从 about 返回首页后想再次进入 about，只能滚轮下滑——键盘 `ArrowUp` / `PageUp` 不会触发任何反馈。这在无障碍角度是一个缺口。

### 10. ⚠️ `process/index.html` 的视频播放器缺少封面

`<video controls preload="metadata" poster="">` 的 `poster` 为空字符串，在视频未加载时显示黑块或浏览器默认样式，与页面整体的高级感不匹配。

### 11. 🆕 chapter-4 的 `nextTarget` 回退到章节总览，打断线性故事流

chapter-4 的 `nextTarget` 是 `'../index.html'`（章节总览），滚轮下滑会从终章直接跳回总览页。按照全站线性故事流（index → about → research → design → chapters → ch1→ch2→ch3→ch4 → process → thanks），用户在终章结束后更自然的预期是进入"制作过程"页。

**建议**：将 chapter-4 的 `nextTarget` 改为 `'../../process/index.html'`，保持线性推进；底部 pager 保留"返回章节总览"作为显式回退入口。

## 四、视觉一致性

### 12. ⚠️ 导航栏 `z-index` 不统一

| 页面 | `.nav` z-index |
|---|---|
| index.html | 20 |
| about | 40 |
| research | 30 |
| design | 30 |
| chapters | 30 |
| process | 30 |
| thanks | 30 |
| chapter 1-4 | 20 |

about 页的 nav z-index 是 40（最高），而首页和章节详情页是 20。如果未来有弹层或 tooltip，z-index 层级混乱会导致遮挡异常。

**建议**：全站统一 `.nav` z-index 为 30 或 40。

### 13. ⚠️ 章节详情页与主站页面的离场 `translateY` 偏移量不一致

四个章节页的离场位移统一为 `translateY(26px)` / `translateY(-26px)`，而 about / research / design / process / thanks 页面统一为 `translateY(24px)` / `translateY(-24px)`。2px 的差异虽小，但在快速翻页时可能产生微妙的"顿挫感"。

**建议**：全站统一为 24px 或 26px。

### 14. ⚠️ 导航栏背景色全站不统一

| 页面 | nav 背景色 |
|---|---|
| index.html | `rgba(246,248,251,0.68)` |
| about | `rgba(246,248,251,0.68)` |
| research | `rgba(245,247,250,0.65)` |
| design | `rgba(245,247,250,0.68)` |
| chapters | `rgba(245,247,250,0.65)` |
| process | `rgba(245,247,250,0.65)` |
| thanks | `rgba(245,247,250,0.65)` |
| chapter-1 | `rgba(244,247,249,0.72)` |
| chapter-2 | `rgba(247,244,239,0.72)` |
| chapter-3 | `rgba(245,243,248,0.72)` |
| chapter-4 | `rgba(244,247,250,0.72)` |

章节页有意使用章节色调（冰蓝 / 暖黄 / 紫调 / 冷蓝），但主站页面之间的 `rgba` 底色和透明度也有差异（`246,248,251` vs `245,247,250`，`0.68` vs `0.65`）。

**建议**：主站页面统一为同一值；章节页的色调偏移可以保留，但透明度应统一（建议全部 `0.68` 或 `0.72`）。

### 15. ⚠️ `about/index.html` 和 `index.html` 的 `--text-main` 色值与其他页面不同

about 页和首页定义 `--text-main: #465564`，而 research / design / chapters / process / thanks 都是 `--text-main: #4a5560`。差值虽小（`#465564` vs `#4a5560`），但在同一浏览会话中切换页面时，正文字色会有可感知的跳变。

**建议**：全站统一为 `#4a5560`（多数页面的值），或统一为 `#465564`。

## 五、内容完整性

### 16. ⚠️ 章节详情页素材区全是占位符

四个章节页的图片 / 视频区全部是 `<div class="placeholder">建议放置...</div>` 和 `.gitkeep`，没有任何实际素材。作为毕业展示站，这是最明显的"未完成"信号。

**建议**：至少为每个章节补充 1-2 张关键截图或概念图，替换掉 placeholder。

### 17. ⚠️ `process/index.html` 的过程记录图库重复使用同一张图

三张 gallery 图片全部指向 `../images/剪贴板图片.jpg`，没有区分"概念草图""场景搭建""测试记录"。

### 18. ⚠️ `thanks/index.html` 的感谢名单是占位文字

`指导教师`、`测试参与者`、`项目协作者`、`答辩评审` 都是通用标签，没有填入真实姓名。

### 19. ⚠️ `about/index.html` 与 `research/index.html` 内容高度重叠

about 页的"研究锚点"三卡片（研究问题 / 理论视角 / 作品定位）与 research 页的"研究锚点"三卡片**文字几乎完全相同**；about 页的"协作机制"三卡片与 design 页的"跨媒介协作机制"也高度重复。用户连续浏览时会感到"看了两遍"。

**建议**：about 页定位为"项目全貌速览"，用更精简的概括性文字；research 页展开数据与论证；design 页聚焦设计决策。三页各守边界，避免复制粘贴。

### 20. ⚠️ `about/index.html` 的"结果验证"数据与 research 页的图表脱节

about 页展示了 `18/20`、`75%`、`70%` 等测试结论数字，但 research 页的图表数据全部基于 117/118 份问卷，而非 20 人测试。两套数据口径不同，但页面间没有交叉引用或说明。
