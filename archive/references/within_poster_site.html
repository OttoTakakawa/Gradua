PROJECT INTRO

项目介绍

这个页面不再是传统论文答辩网页那种纯信息排版，而是从你的海报里提取视觉语汇后，做成更像“作品官网”的形式：先建立气质，再进入内容。

从海报提取到的关键视觉元素

1. 低多边形切面：不只是场景 lowpoly，而是整个版面都带有晶体切片、折面和蒙版感。
2. 大面积留白：背景很轻，信息像漂浮在雾中的碎片，网页也应该保留这种呼吸感。
3. 冷暖双色对照：左侧偏冷蓝，右侧偏暖米，底部又回到蓝紫，适合用来做页面分区和章节识别。
4. 中心人物 + 四翼章节：天然适合做“章节导航页”，四个区域本身就像四个按钮。

建议的网站信息结构

首页：只做视觉开场，主标题用 Within，传达项目气质。
项目介绍：介绍作品主题、玩法、体验目标、核心亮点。
章节导览：直接把海报变成可点击地图，点击后切换到对应章节内容页。
制作过程：展示设定、流程、草图、测试记录，并支持播放本地视频。
感谢：鸣谢老师、同学、参与测试者，也可放二维码或联系方式。
INTERACTIVE POSTER MAP

海报章节导览

这里直接把你的海报当作一个可交互入口。现在我先用 CSS 热区做了四个默认点击区域；后面你完全可以把它替换成你自己勾的蒙版路径、SVG path，或者更精细的多边形热区。

后续你只需要改四个热区的 .shape-1 ~ .shape-4 的 left / top / width / height / clip-path， 就能把点击区域调成你想要的具体轮廓。

CHAPTER 01

孤独的城市

页面可展示雨夜城市章节的概念图、章节简介、关键情绪词与玩法说明。视觉上建议延续海报左上角的冷青蓝，配合几何雨线、稀薄光点、透明楼体，让用户一进入页面就感受到“疏离、迷失、寻找出口”的气氛。

CHAPTER 02

萨沙的家

这一页适合切换成更安静、温暖、低刺激的氛围。你可以放置角色背景、家庭空间的物件细节、电话与交流的触发机制。网页配色建议偏暖米、浅木色、柔和灰，以形成和第一章的明显情绪对照。

CHAPTER 03

皮埃尔的梦想

第三章适合做成梦境式转场页。你可以展示森林、城堡、心理空间、角色象征物等内容。网页中的卡片与背景可以加入更多紫灰色折面，让这一章更像进入另一个记忆层，而不是普通说明页面。

CHAPTER 04

太空之梦

最后一章可以加强科技感与终章感。适合展示飞船、协作修复、共同前进的段落，也可以把最终的情绪收束到“协作同行”这一主题。页面色彩可回到冷蓝，但比第一章更明亮，更有希望感。

PROCESS & LOCAL VIDEO

制作过程

这里适合放草图、建模、场景测试、交互调试、用户测试记录，也可以直接播放你本地的视频文件。

你把本地视频放到项目里的 videos/within-process.mp4，这里就能直接播放。

01｜概念与视觉建立 展示主视觉草图、海报推演、章节结构、角色关系和情绪关键词。
02｜Unity / VR 开发过程 放引擎界面截图、场景搭建前后对比、交互逻辑示意、设备测试记录。
03｜用户测试与迭代 展示试玩现场照片、问题反馈、章节修改点和最终优化结果。
04｜成果输出 可以放答辩海报、宣传图、预告视频、二维码或最终体验剪辑。
