# 液态玻璃效果改动说明

## 改动目标

将导航栏顶部的选中指示器（`.nav-indicator`）从普通毛玻璃效果升级为接近 Apple iOS 26 风格的**液态玻璃（Liquid Glass）**效果。

---

## 一、原来的问题

原版 `.nav-indicator` 只有最基础的毛玻璃：

```css
/* 原版 */
backdrop-filter: blur(28px) saturate(200%) brightness(1.08);
background: linear-gradient(160deg, rgba(220,235,248,0.55), ...);
box-shadow: inset 0 2px 3px rgba(255,255,255,0.80), ...;
```

缺少的东西：
- 没有折射/畸变感（玻璃的核心视觉特征）
- 高光太弱，不像真实玻璃的镜面反射
- 没有玻璃"厚度"感
- 没有动态光泽（静止感太强）

---

## 二、改了哪些地方

### 1. `background` — 模拟凸透镜的渐变层次

```css
background:
  linear-gradient(
    175deg,
    rgba(255, 255, 255, 0.58) 0%,   /* 顶部最亮，模拟光线打在玻璃顶面 */
    rgba(255, 255, 255, 0.22) 16%,
    rgba(215, 235, 252, 0.14) 42%,  /* 中段淡蓝色，模拟玻璃本体的色调 */
    rgba(195, 222, 248, 0.10) 72%,
    rgba(210, 230, 250, 0.22) 100%  /* 底部略亮，模拟底面反光 */
  );
```

**原理**：真实玻璃是有厚度的透明体，顶面和底面都会反射光线，中间是透明的蓝色玻璃本体。这个渐变用 5 个色阶模拟了这个物理现象。

---

### 2. `backdrop-filter` — 加入 SVG 折射滤镜

```css
/* 改后 */
backdrop-filter: url(#lg-distort) blur(32px) saturate(240%) brightness(1.14);
```

| 参数 | 原值 | 新值 | 作用 |
|------|------|------|------|
| SVG 滤镜 | 无 | `url(#lg-distort)` | 对玻璃后方内容产生折射畸变 |
| blur | 28px | 32px | 更深的磨砂感 |
| saturate | 200% | 240% | 玻璃会聚焦光线，颜色更饱和 |
| brightness | 1.08 | 1.14 | 玻璃透光后略微提亮 |

`url(#lg-distort)` 引用的是需要在 HTML 里添加的 SVG 滤镜（见第四节），它会让玻璃后方的内容产生轻微的有机形变，这是液态玻璃最关键的视觉特征。

---

### 3. `box-shadow` — 8 层阴影系统模拟玻璃厚度

```css
box-shadow:
  /* ① 外层白色光晕环 */
  0 0 0 0.5px rgba(255, 255, 255, 0.28),
  /* ② 顶部镜面高光线（最亮，模拟光线打在顶边缘） */
  inset 0 1.5px 0 rgba(255, 255, 255, 0.96),
  /* ③ 内部顶部漫反射光晕 */
  inset 0 4px 14px rgba(255, 255, 255, 0.42),
  /* ④⑤ 左右侧面内高光（模拟玻璃侧壁） */
  inset 2px 0 8px rgba(255, 255, 255, 0.14),
  inset -2px 0 8px rgba(255, 255, 255, 0.14),
  /* ⑥ 底部内阴影（模拟玻璃厚度/重量感） */
  inset 0 -3px 8px rgba(0, 0, 0, 0.05),
  /* ⑦⑧ 外部投影（元素悬浮感） */
  0 8px 28px rgba(0, 0, 0, 0.11),
  0 2px 6px rgba(0, 0, 0, 0.06);
```

**原理**：原版只有 2 层阴影，新版用 8 层分别模拟玻璃的顶面高光、侧面反光、底面阴影和悬浮投影，共同营造出玻璃的立体厚度感。

---

### 4. `::before` 伪元素 — 凸透镜镜面高光

```css
/* 改后 */
background:
  /* 顶部弧形高光：模拟光线打在凸面玻璃顶部形成的月牙形亮斑 */
  radial-gradient(
    ellipse 88% 44% at 50% -2%,
    rgba(255, 255, 255, 0.88) 0%,
    rgba(255, 255, 255, 0.42) 28%,
    transparent 68%
  ),
  /* 底部边缘微光：模拟玻璃底面的折射余光 */
  radial-gradient(
    ellipse 55% 18% at 50% 102%,
    rgba(255, 255, 255, 0.22) 0%,
    transparent 70%
  );
```

**原理**：原版用的是斜向线性渐变，视觉上更像塑料。改为从顶部中心向外扩散的椭圆形径向渐变，模拟凸面玻璃在顶部形成的月牙形镜面高光，这是 iOS 26 液态玻璃最标志性的视觉特征之一。

---

### 5. `::after` 伪元素 — 顶边高光线

```css
/* 改后 */
width: 72%;        /* 原 80%，略收窄让两端渐隐更自然 */
height: 1.5px;     /* 原 1px，更粗更清晰 */
top: 0;            /* 原 top: 1px，贴紧顶边 */
left: 14%;
filter: blur(0.4px);  /* 新增：轻微模糊让高光线更柔和真实 */
background: linear-gradient(
  90deg,
  transparent,
  rgba(255, 255, 255, 1.0) 22%,   /* 原 0.95，改为全白更锐利 */
  rgba(255, 255, 255, 1.0) 78%,
  transparent
);
```

**原理**：这条线模拟玻璃顶边缘的镜面反射，加粗并贴紧顶边后，配合 `blur(0.4px)` 让它看起来像真实的光线折射，而不是生硬的装饰线。

---

### 6. 新增 `@keyframes liquid-shimmer` — 动态光泽扫光

```css
@keyframes liquid-shimmer {
  0%   { transform: translateX(-110%) skewX(-18deg); }
  100% { transform: translateX(210%)  skewX(-18deg); }
}

.nav.is-indicator-ready .nav-indicator::before {
  animation: liquid-shimmer 3.6s cubic-bezier(.4,0,.6,1) infinite;
  animation-delay: 1.2s;
  background:
    /* 扫光条 */
    linear-gradient(90deg, transparent 0%, rgba(255,255,255,0.52) 50%, transparent 100%),
    /* 保留原有的顶部高光和底部微光 */
    radial-gradient(...),
    radial-gradient(...);
}
```

**原理**：iOS 26 的液态玻璃是"活的"，会随光线变化产生流动感。这里用一条倾斜 18° 的半透明白色光带，每 3.6 秒从左向右扫过一次，模拟环境光在玻璃表面的动态反射。`cubic-bezier(.4,0,.6,1)` 让扫光有加速-减速的自然感。

## 三、需要在 HTML 里额外添加的内容

CSS 的 `backdrop-filter: url(#lg-distort)` 需要引用一个定义在 HTML 里的 SVG 滤镜。把下面这段代码放在 `<body>` 内任意位置（建议放在 `<nav>` 之前）：

```html
<svg style="position:absolute;width:0;height:0;overflow:hidden" aria-hidden="true">
  <defs>
    <filter id="lg-distort" x="-12%" y="-12%" width="124%" height="124%"
            color-interpolation-filters="sRGB">
      <!-- 生成有机噪声纹理 -->
      <feTurbulence type="fractalNoise" baseFrequency="0.018 0.022"
                    numOctaves="3" seed="8" result="noise"/>
      <!-- 转为灰度，只保留位移信息 -->
      <feColorMatrix type="saturate" values="0" in="noise" result="gray"/>
      <!-- 用噪声图对背景内容做像素位移，产生折射畸变 -->
      <feDisplacementMap in="SourceGraphic" in2="gray"
                         scale="5" xChannelSelector="R" yChannelSelector="G"/>
    </filter>
  </defs>
</svg>
```

### SVG 滤镜工作原理

```
背景内容（玻璃后方的页面）
        ↓
feTurbulence：生成一张分形噪声图（类似大理石纹路）
        ↓
feColorMatrix：去色，只留下灰度值作为位移向量
        ↓
feDisplacementMap：
  - R 通道值 > 128 → 像素向右偏移
  - R 通道值 < 128 → 像素向左偏移
  - G 通道值 > 128 → 像素向下偏移
  - G 通道值 < 128 → 像素向上偏移
  - scale="5" 控制最大偏移量（像素）
        ↓
产生轻微的有机形变，模拟玻璃折射光线的物理效果
```

### 浏览器兼容性

| 浏览器 | 支持情况 |
|--------|----------|
| Chrome 76+ | 完整支持 |
| Safari 14+ | 完整支持 |
| Firefox | `backdrop-filter` 支持，但 `url()` 部分可能不生效 |

**降级处理**：如果浏览器不支持 `url(#lg-distort)`，会自动忽略该部分，退回到 `blur(32px) saturate(240%) brightness(1.14)` 的纯毛玻璃效果，视觉上仍然好看，不会报错或破版。

---

## 四、改动总结

| 改动点 | 原效果 | 新效果 |
|--------|--------|--------|
| 背景渐变 | 单一蓝色线性渐变 | 5 阶渐变模拟玻璃顶/体/底层次 |
| 折射畸变 | 无 | SVG `feDisplacementMap` 有机形变 |
| 模糊强度 | blur(28px) | blur(32px) |
| 饱和度 | saturate(200%) | saturate(240%) |
| 阴影层数 | 2 层 | 8 层（顶/侧/底/外投影） |
| 顶部高光 | 斜向线性渐变 | 椭圆径向渐变（月牙形镜面） |
| 顶边高光线 | 1px，不透明度 0.95 | 1.5px，全白，带 blur(0.4px) |
| 动态光泽 | 无 | 每 3.6s 扫光一次 |
